## 🚨 주요 내용 요약

### 1. 클로드 코드 자동 승인 기능으로 인한 비밀 값 평문 저장
보안 기업 아피로(Apiiro)의 조사 결과, 앤트로픽의 AI 코딩 도구 '클로드 코드(Claude Code)'가 저장한 설정 파일이 공개 깃허브에 올라가며 총 1,379개의 비밀 값이 노출되었다. 셸 명령 실행 시 '다시 묻지 않기'로 전체 명령을 승인하면 비밀번호나 토큰이 암호화 없이 `.claude/settings.local.json` 파일에 남는다. 클로드 코드는 이를 프로젝트의 `.gitignore`가 아닌 사용자 PC의 전역 제외 목록에만 추가해, 다른 환경이나 클로드의 자동 커밋 과정에서 외부로 유출되는 문제가 발생했다.

### 2. 데이터베이스 비밀번호 등 민감 정보 노출 규모
공개 저장소 10만 3,617곳에서 발견된 설정 파일 중 1,122개(약 1.1%)에서 최소 하나 이상의 비밀 값이 확인되었으며, 과거 기록과 대화 로그까지 합치면 2,539개에 달한다. 노출된 정보는 데이터베이스 비밀번호(379개), SSH 로그인 정보(43개), 깃허브·npm 토큰(42개), AWS 키(23개) 등이며, 의료 기록 DB 비밀번호와 63개 기업의 정보도 포함되었다. 노출된 저장소의 절반은 최소 217일 이상 기본 브랜치에 방치된 상태였다.

### 3. 탐지 도구의 사각지대와 미흡한 버그 대응
조사된 16종의 코딩 에이전트 중 승인된 전체 명령을 프로젝트 파일에 기본 저장하는 도구는 클로드 코드뿐이었다. 또한 기존 비밀 값 탐지 도구인 깃리크스(gitleaks)와 트러플호그(TruffleHog)도 검증 단계를 끈 상태에서는 215개 파일을 놓쳤다. 관련 버그 보고는 2025년 8월부터 여러 차례 접수되었으나, 60일간 활동이 없다는 이유로 자동화 봇에 의해 '계획 없음'으로 닫힌 것으로 알려졌다.

## 💡 핵심 질문 (Q&A)
**Q. 다른 코딩 에이전트 15종과 달리, 왜 유독 클로드 코드(Claude Code)만 승인한 전체 명령을 프로젝트 파일에 기본으로 저장하는가?**<br>
**A.** AI 에이전트의 과도한 권한 남용을 막으려던 보수적 권한 설계와 사용자 편의성 사이의 절충(Trade-off) 때문이다. 클로드 코드는 셸 명령을 자동 승인할 때 `curl *` 같은 광범위한 패턴 대신 **사용자가 허용한 '정확한 명령 문자열' 자체만 화이트리스트에 등록**하여 허용 범위를 최소화하려 했다. 또한 이 권한이 다른 저장소에까지 무분별하게 적용되지 않도록 프로젝트 폴더 내부(`.claude/settings.local.json`)에 영구 저장해, 세션을 재시작해도 '다시 묻지 않기' 설정이 유지되도록 구현했다. 하지만 이 과정에서 명령어 내 평문 비밀번호나 토큰을 마스킹하는 필터링이 누락되었고, 프로젝트의 `.gitignore`가 아닌 로컬 전역 제외 목록에만 의존하면서 오히려 깃허브 유출이라는 보안 허점으로 이어진 것이다.

## 🛡️ 대응 방안 및 탐지 지침
- **비밀 값 선교체:** 깃허브에서 파일을 삭제해도 과거 커밋 기록과 복제 저장소에 남으므로, 파일을 정리하기 전에 노출된 모든 비밀번호와 API 키를 먼저 교체한다.
- **저장소 정리 및 추적 제외:** 저장소와 깃 히스토리에서 `.claude/settings.local.json` 파일을 완전히 제거하고, 프로젝트의 `.gitignore`에 명시적으로 추가한다.
- **안전한 명령 승인 습관:** 셸 명령에 비밀 값을 직접 입력하는 대신 환경 변수나 시크릿 관리 도구를 사용하고, 전체 명령이 아닌 `npm test *` 같은 명령 패턴 단위로만 자동 승인을 허용한다.

## 📖 용어 사전
- **클로드 코드 (Claude Code):** 앤트로픽(Anthropic)이 개발한 터미널 기반 AI 코딩 에이전트로, 코드 작성뿐만 아니라 셸 명령 실행과 깃 커밋 등의 작업을 자율적으로 수행한다.
- **`.gitignore`:** 깃(Git) 저장소에서 버전 관리(추적 및 커밋) 대상에서 제외할 파일이나 폴더 패턴을 지정하는 프로젝트 단위 설정 파일이다.
- **깃리크스 (gitleaks):**  Git 저장소(Repository) 내에 포함된 민감 정보(API Key, 비밀번호, 토큰, 인증서, 개인키 등)를 탐지하는 보안 도구를 의미한다.
- **트러플호그 (TruffleHog):** 소스 코드, Git 커밋 히스토리, 클라우드 스토리지 등에 실수로 노출된 API 키, 비밀번호, 암호화 키, 인증 토큰 같은 민감한 자격 증명(Secrets)을 찾아내고 검증하는 오픈소스 보안 스캐닝 도구이다. 트러플(송로버섯)을 땅속에서 냄새로 찾아내는 돼지(Hog)에서 이름을 따왔으며, Truffle Security에서 개발 및 유지보수하고 있습니다.
