## 🚨 주요 내용 요약

### 1. 방어용 AI 도구 '케언'을 악용한 자율 공격
아마존 위협 인텔리전스는 중국 연계로 추정되는 공격자가 방어 연구용 AI 에이전트 도구 '케언(Cairn)'을 동원해 동아시아 대학 서버를 장악한 사례를 공개했다. 공격자는 인증 없이 열린 서버에 표적 IP와 '셸 접근 권한 확보'라는 목표만 중국어 간체로 입력했고, 이후 48시간 동안의 공격은 대부분 AI 에이전트가 자율적으로 수행했다.

### 2. 끈질긴 실패 끝 제로데이 발견 및 최고 권한 탈취
에이전트는 16시간 동안 레디스(Redis) 148회 공격, 로그4셸(Log4Shell) 시도, 교수진 명부에서 수집한 계정으로 3만 건 이상의 무차별 대입을 시도했으나 모두 실패했다. 그러나 오픈소스 의료 영상 AI 앱 '모나이 레이블(MONAI Label, 0.8.5 이하)'의 업로드 기능에서 경로 조작 제로데이 결함을 스스로 찾아냈다. API 파악부터 임의 파일 쓰기까지 단 11분이 걸렸으며, `sitecustomize.py`에 악성 코드를 심어 최고 관리자(root) 권한의 원격 셸을 확보했다.

### 3. 인간 개입을 통한 확산과 방어 자동화의 시급성
최초 침투 이후 인간 운영자가 개입해 에이전트에 중계 서버(프록시)를 제공하며 두 번째 대학 네트워크로 공격을 확장했다. 아마존은 AI가 휴식 없이 연속 공격을 수행해 방어자의 대응 시간이 급격히 줄어들고 있다며, 확신도 높은 탐지는 자동 대응으로 연결하고 사람은 이를 감독하는 체계로 전환해야 한다고 경고했다.

## 💡 핵심 질문 (Q&A)
**Q. AI 에이전트는 임의 파일 쓰기 취약점을 찾은 뒤, 왜 굳이 `sitecustomize.py` 파일을 변조하고 학습용 API를 호출했는가?**
**A.** `sitecustomize.py`는 파이썬(Python) 인터프리터가 시작될 때마다 자동으로 가장 먼저 불러와 실행하는 초기화 스크립트이기 때문이다. 웹 애플리케이션에 임의 파일을 쓸 수 있더라도 이를 직접 실행할 방법이 없으면 원격 코드 실행(RCE)으로 이어지지 않는다. 따라서 에이전트는 파이썬 경로에 원격 접속 코드를 담은 `sitecustomize.py`를 덮어쓴 뒤, 서버 내부에서 새로운 파이썬 프로세스를 생성하는 '학습용 API'를 트리거로 호출해 악성 코드가 자동으로 실행되도록 유도한 것이다.

## 🛡️ 대응 방안 및 탐지 지침
- **소프트웨어 패치:** 오픈소스 의료 영상 앱 '모나이 레이블(MONAI Label)' 0.8.5 이하 버전을 사용 중인 기관은 개발진이 배포하는 보안 수정판으로 즉시 업데이트한다.
- **탐지 및 자동 대응 체계 구축:** AI 에이전트의 24시간 무중단 공격 속도에 대응하기 위해, 확신도가 높은 이상 징후 탐지 시 수동 검토를 기다리지 않고 자동 차단·격리되도록 보안 체계를 고도화한다.
- **노출 서비스 및 권한 점검:** 레디스(Redis) 등 내부 데이터베이스의 외부 인증 없는 노출을 차단하고, 파이썬 앱 등 서비스 프로세스가 최고 관리자(root) 권한으로 실행되지 않도록 최소 권한 원칙을 적용한다.

## 📖 용어 사전
- **케언 (Cairn):** 출발점과 목표를 일상어로 입력하면 여러 AI 에이전트를 조율해 문제를 해결하도록 설계된 방어 연구용 AI 도구다.
- **모나이 레이블 (MONAI Label):** MONAI ( Medical Open Network for AI )는 의료 영상 분야 의 딥러닝 (DL)을 위한 오픈소스 커뮤니티 지원 프레임워크이다.
- **경로 조작 (Path Traversal):** Path Traversal 또는 Directory Traversal 취약점은 주로 사용자의 입력을 제대로 검증하지 않아 발생하는 보안 취약점이다. 공격자는 상대경로 혹은 절대경로를 사용하여 원래는 접근할 수 없는 파일 또는 의도하지 않은 경로의 파일을 읽고 수정할 수 있으며, 심지어 새로운 파일을 생성할 수도 있다.
    - Zip Slip은 압축 파일 내에 포함된 파일 경로를 악의적으로 조작하여, 압축 해제 시 대상 디렉토리 외부에 파일을 생성하거나 기존 파일을 덮어쓰는 취약점이다. 공격자가 이 취약점을 악용해 생성한 압축파일을 사용자가 압축 해제하면 공격자가 원하는 경로에 파일이 생성될 수 있다.
- **sitecustomize.py:** sitecustomize.py는 파이썬 인터프리터가 시작될 때 내장 site 모듈을 통해 자동으로 임포트하고 실행하는 사이트별 구성 훅 파일이다. site-packages나 PYTHONPATH 등 임포트 경로에 위치하면 개별 스크립트를 수정하지 않고도 해당 환경의 모든 파이썬 실행에 공통 설정을 적용할 수 있다.
- **제로데이:** 해당 취약점이 공표 혹은 발견된 날
    - 제로데이 취약점: 취약점이 발견되고 보안패치가 배포 전까지의 취약점
    - 제로데이 공격: 취약점에 대한 패치가 나오지 않은 시점에서 이루어지는 공격
- **로그4셸(Log4Shell) 공격:** Log4J 취약점이라고도 하는 Log4Shell은 Apache Log4J 2 Java 라이브러리의 일부 버전에서 발생하는 원격 코드 실행(RCE) 취약점이다. Log4Shell을 사용하면 해커가 감염된 시스템에서 원하는 모든 코드를 실행할 수 있으므로 앱과 디바이스를 완전히 제어할 수 있다.
    - Log4Shell이라고도 알려진 Log4j 취약점은 2021년 11월에 Apache Log4j 로깅 라이브러리에서 발견된 매우 심각한 취약점이다. Log4Shell은 기본적으로 해커에게 패치되지 않은 버전의 Log4j를 실행하는 디바이스를 완전히 제어할 수 있는 권한을 부여한다.
- **쿼드런트(Qdrant):** 쿼드런트는 Rust 언어로 개발된 오픈소스 벡터 데이터베이스이자 유사성 검색 엔진이다. 고차원 벡터 데이터를 빠르게 저장하고 검색하며, AI 추천 시스템이나 RAG(검색 증강 생성) 구축에 주로 활용된다.
