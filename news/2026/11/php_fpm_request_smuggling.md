## 🚨 주요 내용 요약

### 1. PHP 지원 전 버전 보안 업데이트 및 치명적 RCE 결함 수정
PHP 개발진은 11월 19일 지원 중인 모든 버전에 대해 보안 업데이트(8.5.13, 8.4.28, 8.3.37, 8.2.36)를 배포했다. 이번 업데이트에는 8.5.13 기준 총 18건의 CVE가 포함되었으며, 가장 심각한 결함은 특정 웹서버 설정 환경에서 로그인하지 않은 공격자가 요청 단 하나로 서버에서 임의의 PHP 코드를 실행할 수 있는 '치명적(Critical)' 등급의 취약점이다.

### 2. PHP-FPM 연결 재사용 환경의 요청 밀반입(CVE-2026-129289)
핵심 결함은 웹서버 뒤에서 PHP 코드를 처리하는 PHP-FPM의 요청 밀반입(Request Smuggling) 취약점이다. 엔진엑스(`fastcgi_keep_conn on`), 아파치(`enablereuse=on`), HAProxy, LSAPI 등에서 웹서버와 PHP-FPM 간의 연결을 끊지 않고 재사용하도록 설정한 상태에서, 애플리케이션이 요청 본문을 끝까지 읽지 않는 조건이 겹치면 공격이 성립한다. 반면 요청마다 연결을 닫는 기본 설정 환경은 공개된 공격 방식의 영향을 받지 않는다.

### 3. 기존 세션 결함 정식 수정 및 구버전 대응
이번 업데이트에는 지난 10월 23일 공개되어 임시 설정 변경(`session.upload_progress.enabled = 0`)으로 대응하던 세션 결함(CVE-2026-115560)과 DOM, SOAP, CGI, PHAR 등 다양한 구성 요소의 패치도 포함되었다. 공식 지원이 종료된 구버전의 경우, 외부 패키지 관리자 온드레이 수리(Ondřej Surý)가 PHP 5.6 버전까지 소급 적용할 수 있는 패치 패키지를 별도로 배포했다.

## 💡 핵심 질문 (Q&A)
**Q. 공격자가 보내는 모든 HTTP 요청이 위험한가, 아니면 특히 위험한 특정 요청이 존재하는가?**<br>
**A.** 모든 요청이 위험한 것은 아니며, **애플리케이션이 요청 본문(Body)을 끝까지 읽지 않고 종료하는 엔드포인트로 '조작된 FastCGI 바이너리 데이터'를 실어 보내는 요청**이 특히 치명적이다. 일반적인 GET 요청이나 앱이 본문을 정상적으로 모두 소비하는 POST 요청은 소켓 버퍼에 잔여 데이터를 남기지 않으므로 공격이 성립하지 않는다. 반면, 본문을 읽지 않는 경로(예: 인증 실패로 즉시 응답을 반환하거나 본문을 무시하는 페이지)에 본문을 억지로 담아 보내면서 그 안에 FastCGI 프로토콜 규격에 맞춘 악성 제어 패킷(예: `auto_prepend_file` 같은 PHP 설정 주입)을 숨기면, 연결을 재사용하는 PHP-FPM이 이를 다음 정상 요청의 설정으로 오인해 원격 코드 실행(RCE)으로 이어지게 된다.

## 🛡️ 대응 방안 및 탐지 지침
- **버전 업데이트:** 운영 중인 PHP 버전을 즉시 최신 보안 패치 버전(`8.5.13`, `8.4.28`, `8.3.37`, `8.2.36`)으로 업그레이드할 것
- **임시 조치 (연결 재사용 해제):** 즉각적인 패치가 어렵다면 앞단 웹서버(NGINX, Apache, HAProxy 등)에서 PHP-FPM 연결 재사용 옵션을 비활성화할 것
- **네트워크 격리:** PHP-FPM 및 LSAPI 포트가 외부나 신뢰할 수 없는 네트워크에 직접 노출되지 않도록 방화벽 및 바인딩 설정을 점검할 것

## 📖 용어 사전
- **PHP-FPM (FastCGI Process Manager):** NGINX나 아파치 같은 웹서버 뒤에서 실제 PHP 스크립트 요청을 받아 처리하고 결과를 반환하는 프로세스 관리자다.
- **요청 밀반입 (Request Smuggling):** 앞단 서버(웹서버·프록시)와 뒷단 서버(WAS·PHP-FPM 등)가 요청의 경계나 길이를 해석하는 방식의 차이를 악용해, 정상 요청 속에 악성 요청을 몰래 끼워 넣는 공격 기법이다.
- **FastCGI:** 웹서버와 외부 애플리케이션 프로그램(PHP 등)이 통신하기 위한 바이너리 프로토콜로, 요청마다 프로세스를 새로 생성하지 않고 유지해 성능을 높인다.
- **LSAPI (LiteSpeed Server API):** 라이트스피드(LiteSpeed) 웹서버와 PHP 등의 스크립트 언어 간에 고속으로 통신하기 위해 설계된 전용 인터페이스다.
