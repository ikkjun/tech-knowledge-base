파이썬에서 `venv`(Vircual Environment)는 프로젝트마다 독립된 파이썬 실행 환경(격리 공간)을 만들어 주는 표준 도구이다. 운영체제(OS)나 전역(Global) 환경에 파이썬 패키지를 그냥 설치(`pip install`)하면 **패키지 버전 충돌(Dependency Conflict)** 문제가 발생한다. 그래서 가상환경 없이 컴퓨터 전체에 하나만 설치하면 프로젝트 B를 위해 라이브러리를 업데이트 하는 순간 프로젝트 A의 코드가 깨져서 동작하지 않게 된다. 하지만 `venv`를 쓰면 **프로젝트마다 방을 따로 파서(가상 환경)**, 그 방 안에서만 패키지를 설치하고 삭제할 수 있어 다른 프로젝트나 OS에 전혀 영향을 주지 않는다.

### 동적 타이핑
변수의 메모리 공간을 생성하는 시점이 프로그램이 실행되는 시점에 생성되는 것을 의미한다.(타입의 정의가 완료되는 시점)

- 컴파일 언어의 경우
    - ```int num=10```과 같이 실행 이전에 변수의 타입을 정의한다.
- 파이썬의 경우
    - num=8과 같이 선언한다.

프로그램이 실행되는 시점인 8의 값이 저장될 때 인터프리터가 정수(int)임을 판단해서 메모리의 타입을 결정한다. 파이썬은 프로그램의 실행 시점에 동적으로 판단해서 적용되는 것을 동적으로 자료형을 결정한다.

## 변수
- 변수란 데이터의 메모리의 주소값을 가지는 데이터이다.★
- 데이터마다 저장 형식(객체)이 다르다.
- 파이썬의 모든 데이터는 객체로 저장한다.★
- 파이썬에서 사용하는 변수는 객체를 가리키는 것이다. 변수는 메모리의 주소 값을 가지고 있다.
- 객체(저장된 데이터) = 자료형


```python
num = 10
```

10 데이터를 메모리 공간에 저장하고, 10이 저장된 메모리 공간의 주소를 num이라고 하는 메모리 공간에 저장한다.

변수: num = 0x1000<br>
주소 0x1000값 = 10


- [1, 2, 3, 4, 5] 값을 가지는 리스트 데이터(객체)가 자동으로 메모리에 생성됨. 
- 변수 a는 [1, 2, 3, 4, 5] 리스트가 저장된 메모리의 주소를 가리킴.

### 변수 선언 방법

- =(assignment) 기호를 사용
    - 변수 이름 = 변수에 저장할 값(데이터)

### 변수의 명명 규칙

- 문자(A-z)와 숫자(0-9), _(underscore)를 사용할 수 있음
- 변수명은 대소문자가 구분됨
- 변수명은 의미있는 단어로 사용하는 것이 좋음
- 변수명이 숫자로 시작할 수 없음
- 변수명에는 공백이 포함될 수 없음
- 예약어를 변수명으로 사용할 수 없음

```python
b = a = [1, 2, 3]
```

위와 같이 b변수에 a변수를 대입하면 b가 가지는 겂은?

메모리에 [1, 2, 3]의 리스트가 저장되어, a는 리스트의 주소를 가리키며, b는 a가 가리키는 리스트의 주소를 가리키게 된다.

```python
b = a = [1, 2, 3]
a is b              # True
```

is는 메모리의 주소값을 비교한다.

    ```python
    # ====hi====
    # hi!!!!!!!!
    ```
- 소수점 표현
    ```python
    y = 3.42134234
    z = 123456789.42134234

    print(f'{y:0.4f}') # 소수점 4자리까지만 표현
    print(f'{y:10.4f}') # 소수점 4자리까지만 표현하고 총 자릿수를 '10'으로 맞춤
    print(f'{z:10.4f}') # 소수점 4자리까지만 표현하고 총 자릿수를 '10'으로 맞춤
    print(f'{z:20.4f}')
    # 3.4213
    #     3.4213
    # 123456789.4213
    #       123456789.4213
    ```
    1. 포맷팅 문법의 실제 의미: `{값: 폭.정밀도f}`
        - `폭(Width)`**(앞의 숫자)**:<br>부호, 정수부, 소수점(.), 소수점 아래 숫자를 **모두 합친 전체 문자열의 최소 길이**이다.
        - `정밀도(Precision)`**(뒤의 숫자)**:<br>소수점 아래에 표시할 자릿수(4자리)이다.
    2. 왜 정수 9자리가 안 잘리고 다 나올까?<br>
    파이썬의 숫자 포맷팅은 "데이터의 손실을 방지하기 위해, 지정한 폭(`width`)이 실제 숫자의 전체 길이보다 작으면 폭 설정을 무시하고 전체 숫자를 그대로 출력한다"는 대원칙이 있다.<br>
    `z = 123456789.42134234`를 `.4f`로 표현하면:<br>
        - 정수부: `123456789`(9글자)
        - 소수점: `.`(1글자)
        - 소수부: `4213`(4글자)
        - → 실제 필요한 최소 자리수=총 14자리
    따라서 이미 14자리이므로 10을 무시하고 14자리를 출력한다. 만약 폭(`width`)을 실제 길이보다 크게 지정하면(예: `20`), 그 때 비로소 남는 앞 공간이 공백으로 채워진다.

### bool

#### 불 자료형(bool)이란?
- 참(True)과 거짓(False)을 나타내는 자료형
    - type() 함수를 사용하여 자료형 확인
    - 조건문의 반환 값으로도 사용됨
- 자료형의 참과 거짓<br>

    | 값 | 참 또는 거짓 |
    | :--- | :--- |
    | "python" | 참 |
    | "" | 거짓 |
    | [1, 2, 3] | 참 |
    | [] | 거짓 |
    | (1, 2, 3) | 참 |
    | () | 거짓 |
    | {'a': 1} | 참 |
    | {} | 거짓 |
    | 1 | 참 |
    | 0 | 거짓 |
    | None | 거짓 |
    
    논리적으로 값이 있는지(True) 없는지(False)를 판단하게 된다.

- bool()함수
    - 자료형의 참/거짓을 식별하는 내장 함수
    - 문자열의 참/거짓
        - 'python' 문자열은 빈 문자열이 아니므로 True 리턴

    A. 파이썬(CPython 인터프리터) 내부에는 정수 인터닝(Integer Interning)이라는 최적화 기법이 적용되어 있다. 파이썬 인터프리터가 부팅(시작)될 때, 프로그램 전체에서 가장 빈번하게 사용되는 -5부터 256까지의 정수 객체들을 메모리에 미리 배열 형태로 생성해 둔다. 그래서 x와 y는 완전히 동일한 메모리 주소를 가리키게 되므로 `x is y`의 결과가 `True`가 나온다. `-5 ~ 256` 범위를 벗어나는 정수는 기본적으로 미리 캐싱해 두지 않기 때문에 동작이 달라질 수 있다.

#### 딕셔너리 자료형

- 딕셔너리(dictionary)

    - 연관 배열(associative array) 또는 해시(hash)
    - Key와 Value를 한 쌍으로 갖는 자료형
    - 순차적(sequential)으로 해당 요소 값을 구하지 않고, Key를 통해 Value를 바로 얻는 것이 특징
    - 예시: dict => json: 문서 유형(규칙)

    - Key와 Value의 쌍 여러 개(Key : Value)가 {}로 둘러싸임
    - 각 요소는 쉼표(,)로 구분됨<br>
        ```{key1: value1, key2: value2, key3: value3, ...}```
- 딕셔너리 쌍 추가, 삭제하기
    - 딕셔너리 쌍 추가하기
        ```python
        dict_2 = {1: 'aaa'}
        dict_2[2]='bbb'
        dict_2['name'] = "Cho"
        dict_2[3] = [1,2,3]
        dict_2[3,4] = [1,2]
        print(dict_2)           # {1: 'aaa', 2: 'bbb', 'name': 'Cho', 3: [1, 2, 3], (3, 4): [1, 2]}

        print(dict_2.get(3,4))    # [1, 2, 3] 4는 키로 딕셔너리에 해당하는 키를 찾지 못 하는 경우 출력되는 기본 값
        print(dict_2.get((3,4)))  # [1, 2]
        ```
    - 딕셔너리 요소 삭제하기
        - del 함수 사용
            ```python
            del dict_2[3] # {1: 'aaa', 2: 'bbb', 'name': 'Cho', (3, 4): [1, 2]}
            ```
- 딕셔너리를 사용하는 방법
    - 딕셔너리에서 Key를 사용해 Value 얻기
        - 리스트나 튜플, 문자열은 요소 값 접근 시 인덱싱이나 슬라이싱 기법 중 하나를 사용
        - 딕셔너리는 Key를 사용해 Value 접근
        - 딕셔너리를 만들 때 주의할 사항
            - 딕셔너리에는 동일한 Key가 중복으로 존재할 수 없음
            - 리스트는 그 값이 변할 수 있기 때문에 Key로 쓸 수 없으나 Value에는 아무 값이나 가능
                ```python
                dict_2[[1,2]] = 3
                # TypeError: unhashable type: 'list'
                ```
                <a id="q-dict-hash"></a>Q. 왜 리스트는 딕셔너리의 키로 쓸 수 없을까?<br>
                A. 파이썬의 딕셔너리는 해시 테이블 자료구조로 구현되어 있어 키를 반드시 해시 함수에 넣어 정수 해시값을 계산한 뒤 메모리 버킷 위치를 결정한다. 

                해시 테이블이 정상적으로 동작하려면 한 번 계산된 해시값은 객체의 수명이 다할 때까지 절대로 변하면 안 된다. 하지만 리스트는 가변(Mutable) 객체이다. 생성된 이후에도 ```append(), pop()```, 요소 값 변경 등으로 내부 데이터가 언제든지 바뀔 수 있다. 만약 내부 데이터가 바뀌었는데도 해시값이 그대로라면 무결성이 깨지고, 데이터가 바뀔 때마다 해시값이 달라진다면 처음에 저장해 둔 메모리 버킷의 위치를 다시는 찾아갈 수 없게 된다.

                반면 튜플은 불변(Immutable) 객체이다. 데이터가 고정되어 있으므로 언제 해시 함수를 호출해도 항상 동일한 해시값을 반환한다.

                튜플 안에 다시 리스트가 들어있는 경우(예: (1, [2, 3]))는 튜플 자체는 불변이지만 내부 요소가 가변이므로 마찬가지로 ```unhashable```에러가 발생한다. 키로 쓰이는 객체는 내부의 모든 요소까지 완전히 불변이어야 한다.
- 딕셔너리 관련 함수
    - Value 리스트 만들기: values
        - Value만을 모아 dict_values 객체 리턴
    - Key, Value 쌍 얻기: items
        - Key와 Value의 쌍을 튜플로 묶어 dict_items 객체 리턴
    - Key:Value 쌍 모두 지우기: clear
        - 딕셔너리 내의 모든 요소 삭제
        - 빈 딕셔너리는 {}로 표현
    - 해당 Key가 딕셔너리 안에 있는지 조사하기: in
        - Key가 딕셔너리 안에 존재하면 True, 존재하지 않으면 False 리턴
    - Key로 Value 얻기: get
        - Key에 대응되는 Value 리턴
        - 존재하지 않는 키 사용 시 None 리턴
            - 오류를 발생시키는 list와 차이가 있음
        - Key값이 없을 경우 미리 정해둔 디폴트 값을 대신 가져오도록 지정 가능

#### 집합 자료형

- 집합(set)
    - 집합에 관련된 것을 쉽게 처리하기 위해 만든 자료형
    - set 키워드를 사용하여 생성
        - set()에 리스트를 입력하여 생성
            ```python
            set_1 = set([1, 2, 3, 4, 5, 1, 3, 5])
            print(set_1)                            # {1, 2, 3, 4, 5}
            print(type(set_1))                      # <class 'set'>
            ```
    - set()에 문자열을 입력하여 생성
        ```python
        print(set("hello")) # {'h', 'o', 'l', 'e'}
        ```
- 집합 자료형의 특징
    1. 중복을 허용하지 않음
    2. 순서가 없음(Unordered)
        - 리스트나 튜플은 순서가 있기 때문에 인덱싱을 통해 요소 값을 얻지만 set 자료형은 순서가 없기 때문에 인덱싱 사용 불가(딕셔너리와 유사)
        - 인덱싱 사용을 원할 경우 리스트나 튜플로 변환이 필요하다.
            - list(), tuple()함수 사용
- 교집합, 합집합, 차집합 구하기: set자료형을 유용하게 사용할 수 있다.
    - 교집합 구하기
        - '&' 기호나 intersection()함수 사용
    - 합집합 구하기
        - '|' 기호나 union() 함수 사용
    - 차집합 구하기
        - '-' 기호나 difference() 함수 사용
- 집합 자료형 관련 함수
    - 값 1개 추가하기: add
    - 값 여러 개 추가하기: update
    - 특정 값 제거하기 - remove
