## <a id="ch01"></a>Chapter 01 나의 첫 머신러닝

### 01-1 인공지능과 머신러닝, 딥러닝

#### 인공지능이란

- **인공지능**(artificial intelligence)은 사람처럼 학습하고 추론할 수 있는 지능을 가진 컴퓨터 시스템을 만드는 기술이다.

- **인공일반지능**(artificial general intelligence) 혹은 **강인공지능**(Strong AI)은 사람과 구분하기 어려운 지능을 가진 컴퓨터 시스템을 말한다.
- **약인공지능**(Weak AI)은 특정 분야에서 사람의 일을 도와주는 보조 역할만 가능하다.

#### 머신러닝이란

- **머신러닝**(machine learning)은 규칙을 일일이 프로그래밍하지 않아도 자동으로 데이터에서 규칙을 학습하는 알고리즘을 연구하는 분야이다.
- 컴퓨터 과학 분야의 대표적인 머신러닝 라이브러리는 **사이킷런**(scikit-learn)이다.

#### 딥러닝이란

- 많은 머신러닝 알고리즘 중에 **인공 신경망**(artificial neural network)을 기반으로 한 방법들을 통칭하여 **딥러닝**(deep learning)이라고 부른다.
- **텐서플로**(TensorFlow)와 **파이토치**(PyTorch)가 대표적인 라이브러리이다.

### 01-3 마켓과 머신러닝

#### 생선 분류 문제

- **특성**(feature)은 데이터의 특징이다.
- **산점도**(scatter plot)는 x, y축으로 이루어진 좌표계에 두 변수(x, y)의 관계를 표현하는 방법이다.
- 파이썬에서 과학계산용 그래프를 그리는 대표적인 패키지는 **맷플롯립**(matplotlib)이다.
- **임포트**(import)란 따로 만들어 둔 파이썬 패키지(클래스와 함수의 묶음)를 사용하기 위해 불러오는 명령이다.
- 산점도 그래프가 일직선에 가까운 형태로 나타나는 경우를 **선형**(linear)적이라고 한다.

#### 첫 번째 머신러닝 프로그램

- 모델에 데이터를 전달하여 규칙을 학습하는 과정을 **훈련**(training)이라고 한다.

#### 도미와 빙어 분류

- 머신러닝 프로그램에서는 알고리즘이 구현된 객체를 모델이라고 부른다.
- 정확도는 정확한 답을 몇 개 맞혔는지를 백분율로 나타낸 값이다. 사이킷런에서는 0~1 사이의 값으로 출력된다.
    - 정확도 = 정확히 맞힌 개수 / 전체 데이터 개수

## <a id="ch02"></a>Chapter 02 데이터 다루기

### 02-1 훈련 세트와 테스트 세트

#### 지도 학습과 비지도 학습

- 머신러닝 알고리즘은 크게 **지도 학습**(supervised learning)과 **비지도 학습**(unsupervised learning)으로 나눌 수 있다.
    - 지도 학습 알고리즘
        - 지도 학습은 데이터와 정답을 **입력**(input)과 **타깃**(target)으로 이루어진 **훈련 데이터**(trainging data)가 필요하다.
        - 입력으로 사용된 길이와 무게를 **특성**(feature)라고 한다.
        - 지도 학습은 정답(타깃)이 있으니 알고리즘이 정답을 맞히는 것을 학습한다.
    - 비지도 학습 알고리즘
        - 타깃 없이 입력 데이터만 사용한다.

#### 훈련 세트와 테스트 세트

- 평가에 사용하는 데이터를 **테스트 세트**(test set), 훈련에 사용되는 데이터를 **훈련 세트**(train set)라고 부른다.
- 훈련에 사용한 데이터로 모델을 평가하는 것은 적절하지 않으므로 훈련 데이터에서 일부를 떼어 내어 테스트 세트로 사용해야 한다.
- 하나의 생선 데이터를 **샘플**(sample)이라고 부른다.
- 리스트처럼 배열의 요소를 선택할 때는 배열의 위치, 즉 **인덱스**(index)를 지정한다.
- **슬라이싱**(slicing)은 콜론(:)을 가운데 두고 인덱스의 범위를 지정하여 여러 개의 원소를 선택할 수 있다.
    - 슬라이싱을 사용할 때는 마지막 인덱스의 원소는 포함되지 않다.
    - '0:5'와 같이 처음부터 시작되는 슬라이싱의 경우 0을 생략하고 쓸 수 있다.
    - 마지막 원소까지 포함할 경우 두 번째 인덱스를 생략할 수 있다(예: `fish_data[44:]`)
